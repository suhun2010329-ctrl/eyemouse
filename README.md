# 아이마우스 (com.jel.eyemouse)

전면 카메라로 머리/시선을 추적해 화면 커서를 움직이고, 응시 유지나 눈 깜빡임으로 탭하는 안드로이드 앱.

## 빌드
- **GitHub Actions**: 저장소에 올리고 `main`에 push → Actions 탭 → 완료된 실행의 `eyemouse-debug-apk` 다운로드
- **Android Studio**: 폴더 열기 → Run. 얼굴 모델(`face_landmarker.task`)은 첫 빌드 때 자동 다운로드됨

요구: Android 8.0(API 26) 이상, 전면 카메라

## 첫 실행
1. 카메라 권한 허용
2. 접근성 → 설치된 앱 → **아이마우스** 켜기
   - 회색으로 막혀 있으면: 설정 → 앱 → 아이마우스 → 우측 상단 ⋮ → **제한된 설정 허용**
3. **시작** → 편한 자세로 화면을 본 상태에서 **센터 맞추기**

## 조작
| 동작 | 결과 |
|---|---|
| 커서를 한곳에 멈춤 (기본 1초) | 탭 (초록 링) |
| 두 눈 0.3~1.2초 감았다 뜨기 | 탭 (깜빡임 모드) |
| 두 눈 2초 이상 감기 | 일시정지/재개 |
| 알림의 버튼 | 일시정지 · 센터 · 종료 |

## 모드
- **머리 움직임(기본)**: 코끝 방향 = 커서. 가장 안정적. 감도·반전 조절 가능
- **시선**: 9점 캘리브레이션 후 사용. 폰 카메라 특성상 오차 1~3cm 수준이라 큰 버튼 위주로 적합. 자세·거리·화면 방향이 바뀌면 재캘리브레이션

## 구조
| 파일 | 역할 |
|---|---|
| `TrackerService` | 포그라운드 서비스, CameraX 전면 카메라 |
| `FaceTracker` | MediaPipe Face Landmarker (478점 + 깜빡임 blendshape) |
| `FeatureExtractor` | 머리 회전량, 홍채 위치 계산 |
| `GazeModel` | 시선 → 화면 좌표 2차 회귀 (캘리브레이션) |
| `CursorController` | 1€ 필터 스무딩, 응시/깜빡임 클릭 판정 |
| `EyeMouseAccessibilityService` | 커서 오버레이, `dispatchGesture` 탭 |
| `CalibrationActivity` | 9점 캘리브레이션 |

카메라 영상은 기기 안에서만 처리되며 저장·전송하지 않음.
